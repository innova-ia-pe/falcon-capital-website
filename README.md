# Falcon Capital Website

Repositorio del proyecto de implementación del nuevo sitio web de Falcon Capital.

- [`prototipo/`](prototipo/README.md): prototipo navegable del diseño aprobado (B «Impulso», banner «Vidrio»),
  publicado en https://innova-ia-pe.github.io/falcon-capital-website/ desde la rama `demo`.
- [`wordpress/`](wordpress/README.md): tema hijo y widgets de Elementor para construir el sitio en WordPress.
